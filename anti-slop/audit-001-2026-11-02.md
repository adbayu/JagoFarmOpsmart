# Antislop Audit 001 — Kolab Standup Sync

What this change does: It links each OpSmart member to a Kolab session, encrypts that session for the member, and queues published standups for headless delivery after 12.00 WIB. It also adds per-member delivery status, retry, and disconnect controls.

## Must fix before production activation

1. **Kolab UI selectors are not verified in a live session** (`src/modules/kolab-sync/automation.ts:47-116`)
   - **What this is:** The worker finds Kolab's greeting, date button, modal, and save control through visible page elements.
   - **Problem:** No linked member session or live delivery was used during implementation. If the current Kolab page differs from the inspected UI, the worker will stop or mark the delivery for review instead of sending it.
   - **Fix:** After server setup, do a controlled acceptance run with one member account and a designated test report, then confirm the date and saved result in Kolab before enabling every member.
   - **If we skip it:** The automation may leave reports waiting for manual review.

## Should fix

2. **The delivery state machine has no automated regression tests** (`src/modules/kolab-sync/worker.ts:25-164`, `src/modules/kolab-sync/session.ts:24-56`)
   - **What this is:** The new code claims queued reports, enforces the WIB cutoff, encrypts account state, and handles retries or uncertain submissions.
   - **Problem:** TypeScript and build checks cannot catch a changed SQL transition that skips a report or retries after a submit whose result is unknown. No tests were added or run for these paths.
   - **Fix:** Add focused database and browser-mock tests for the cutoff, claim lease, session encryption binding, retry limit, and uncertain-submit review state.
   - **If we skip it:** A later change can regress delivery behavior without failing the build.

Not checked: Migration against the deployment database, member session linking, and a live Kolab submission. No real report was submitted during implementation.

Verdict: fix 1 and 2 before production activation.
