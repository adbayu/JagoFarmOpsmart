## Phase 2

Lingkup lokal yang disetujui selesai; urutan dan dependensi ada di `docs/implementation-roadmap.md` bagian
“Phase 2 — Circular farming dan kolaborasi”. Membership mendukung akses setara lintas
modul; Owner menambahkan akun lokal terdaftar dan dapat mengeluarkan anggota lewat halaman Anggota.
Catatan sebelumnya tetap menyimpan actor asli. Waste
bisa dicatat serta ditransisikan dengan histori audit bernama tanpa perubahan stok atau biaya otomatis; catatan tersebut
dapat dipilih sebagai input batch maggot. Halaman Maggot mencatat input, observasi, panen,
pemakaian, sisa, dan penutupan batch tanpa konversi satuan. Batch selesai dapat diposting
secara eksplisit sebagai `STOCK_IN` ke lot aktif kategori `FEED` dengan satuan sama;
provenance tersimpan atomik dan jumlah sisa membatasi posting. Transfer air kolam ke area
tanam mencatat jumlah liter, tanggal, actor, dan catatan opsional secara append-only tanpa
perubahan stok/biaya. Dua jalur sirkular yang ditentukan sumber produk telah tersedia;
konversi dan jalur tambahan belum ditentukan. Inbox notifikasi
tersedia sebagai outbox/worker lokal dengan read state per anggota dan
alert jadwal/stok; migrasi 012 dan grant runtime diverifikasi pada PostgreSQL 18.4 lewat Task 20. Advanced Analytics menampilkan tren produksi bulanan,
biaya POSTED per kategori, volume transfer air tercatat per pasangan unit/bulan, input
limbah ke batch maggot serta hasil maggot per bulan/satuan, dan perbandingan dua siklus
untuk panen serta biaya yang tertaut langsung. Survival, growth, dan feed efficiency
tetap `UNAVAILABLE` sampai definisi dan data yang diperlukan tersedia. Deployment
produksi Phase 2 belum diverifikasi.

## Phase 3

P3-01 sudah memiliki migration, registry perangkat, API ingest generik, worker retensi,
dan halaman `/devices` di branch lokal `codex/p3-01-iot-telemetry`. Suite lokal lulus
126/126, typecheck, dan build lulus. Tes khusus PostgreSQL telah ditambahkan tetapi
belum dijalankan karena `TEST_DATABASE_URL` tidak tersedia; deployment dan kompatibilitas
perangkat nyata belum diverifikasi. Threshold/alert P3-02 belum dibuat.

RAG-01 tetap berupa draft keputusan. Belum ada knowledge center yang berjalan, katalog
sumber dalam aplikasi, ingestion pipeline, endpoint/chat RAG, atau vector index. Belum
ada SOP internal yang diunggah/disetujui, dan pilihan hosting, retensi, provider/model,
serta biaya masih menjadi gate. P3-04 baru disetujui pada tingkat desain; belum ada
implementasi rekomendasi.

## Yang terlihat di UI sekarang

- Login dan pendaftaran akun tersedia.
- Farm manager menampilkan buat/edit/arsip dan pilihan farm aktif setelah sesi valid.
- Halaman Anggota menampilkan anggota farm; Owner dapat menambahkan akun yang sudah
  mendaftar dengan email OpSmart yang sama.
- Menu ikan, ayam, dan tanaman memuat daftar/form unit pada farm aktif; ikan
  memiliki detail kolam dan daftar siklus terkait, ayam memiliki detail kandang,
  dan tanaman memiliki detail area tanam.
- Menu Siklus menampilkan daftar, pembuatan siklus untuk ketiga tipe unit,
  komoditas, detail dan status, serta observasi pada siklus aktif.
- Halaman farm, unit, dan modul yang belum aktif memakai gambar, header, kartu,
  dan aksen warna yang konsisten dengan dashboard.
- Dashboard menampilkan jumlah unit/siklus, aktivitas, biaya mentah, produksi,
  revenue, HPP/COGS dan profit dari SQL; kekurangan data finance memiliki alasan.
- Menu Jadwal memiliki aktivitas, transisi status, dan form pemakaian stok.
  Persediaan memiliki item, lot, saldo, pergerakan stok dan riwayat. Biaya
  dapat dicatat dan diklasifikasikan. Produk, panen, penjualan, pembayaran/refund,
  HPP siklus, dashboard finance dan analitik produksi sudah aktif. Waste organik dapat
  dicatat terpisah dari saldo inventory dan biaya; batch maggot kini dapat dibuat dan
  ditelusuri pada halaman tersendiri. Halaman Transfer air mencatat perpindahan manual
  dari kolam ikan ke area tanam beserta pembuat dan waktu pencatatan.
- Preview interaktif dapat memakai API PGlite lokal lewat
  `npm run dev:server:preview`; data tersimpan di `.pglite/preview` dan tidak
  terhubung ke database produksi. API PostgreSQL dijalankan terpisah dengan
  `npm run dev:server`.
